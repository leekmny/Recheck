# 정식 모델 비교에서 제외

이 폴더의 최초 모델 응답은 exploratory/invalid_blinding입니다. 원 소스의 고정 출력 프로그램 주석에 `Deliberately different behavior`라는 의도 힌트가 포함되었습니다. 두 LLM 조건의 수치를 정식 성능 비교나 최종 결과 표에 사용하지 않습니다. 그대로 보존한 실패 경위 자료입니다.

simple 실행은 모델 메시지와 무관하며 실제 입력·바이너리 SHA를 검증한 뒤 v2에서 관측을 재사용할 수 있습니다. 최초 Engine 프로세스는 구현 변경과 겹쳐 정확한 loaded source identity를 확정할 수 없으므로 최종 RECHECK 측정에도 사용하지 않습니다. v2에서 새 프로세스로 제품 경로를 다시 호출합니다.

정식 결과는 같은 상위 폴더의 `capstone-20261118-v2`를 확인하세요. v2는 원 C 소스의 모든 주석을 동일 규칙으로 제거하고 원문/변환 SHA를 기록합니다. 정답·입력·바이너리는 바꾸지 않습니다.
