# Recheck에서 AI 연결하기

**0.1.3은 새 사용자에게 Gemini 무료 연결을 기본으로 안내하고 GPT를 추천 선택으로 제공합니다.** 업데이트해도 저장된 AI·모델·예산은 유지합니다. 기본 안내만으로 인증이나 실제 응답이 준비됐다고 표시하지 않습니다.

## Gemini 무료로 시작하기

1. **시작하기 → Gemini 무료로 시작하기**를 누릅니다.
2. Google AI Studio에서 본인의 API 키를 발급하고 프로젝트가 **Free tier**인지 직접 확인합니다.
3. 가려진 **Gemini 개인 API 키 보안 입력**에 키를 붙여넣고 무료 프로젝트 확인·근거 전송 동의 두 항목을 확인합니다.
4. **Gemini 키 보안 저장하고 응답 확인**을 누릅니다. Windows 현재 사용자 DPAPI로 키를 보호하고 입력값을 지웁니다. 사용할 수 있는 무료 모델 목록과 실제 기본 응답·JSON 형식·검사 결과 저장을 확인한 뒤 기본 분석 AI로 선택합니다. 실패·취소·설정 변경 시 이전 선택을 유지합니다.

신규 기본 모델은 실제 계정에서 검증한 **Gemini 3.5 Flash-Lite (`gemini-3.5-flash-lite`)**입니다. 기본 예산은 문맥16384·출력4096·업무당 최대5회·대기300초이며 기존 프로필의 예산은 보존합니다. [키 발급과 무료 연결 안내](GEMINI_FREE_SETUP.md)를 따라 준비하세요.

앱에 개발자 공용 키는 없고 유료 모델·결제 계정으로 자동 전환하지 않습니다. API 응답 성공만으로 무료 프로젝트가 증명되지는 않습니다. 무료 입력·응답의 데이터 이용과 요청 제한은 [Google 가격표](https://aistudio.google.com/docs/pricing), [사용 한도](https://aistudio.google.com/docs/rate-limits)를 확인하세요.

## 추천 GPT로 연결하기

GPT를 선택하면 ChatGPT 로그인으로 시작할 수 있습니다. 이 연결에는 API 키나 모델 ID를 직접 입력할 필요가 없습니다.

1. **시작하기**의 안내 버튼 또는 **설정 → 분석 AI 연결**에서 **ChatGPT로 연결하고 자동 설정**을 누릅니다.
2. 브라우저가 열리면 사용할 계정으로 로그인하고 Recheck 연결을 승인합니다. 이미 연결된 계정이면 이 단계를 다시 요구하지 않습니다.
3. 앱이 사용 가능한 모델 조회 → 추천 모델 선택 → 실제 응답 확인 → 기본 AI 저장 → 설치된 도구 확인을 진행합니다. 연결 과정은 화면에 순서대로 표시됩니다.
4. 준비가 끝나면 **프로그램 비교** 화면으로 이동합니다. 기존 프로그램과 새 프로그램을 고르고, 넣어 볼 값을 작성한 뒤 **비교 시작하기**를 누릅니다.

GPT의 추천 모델은 **GPT-6.1 Sol (`gpt-6.1-sol`)**입니다. 해당 모델이 계정 목록에 없으면 계정에 표시되는 첫 모델을 고릅니다. 이미 직접 지정한 사용 가능 모델은 보존합니다. 연결 성공 후 재실행해도 기본 AI와 검증된 기능을 유지합니다.

연결 버튼은 분석에 필요한 입력·실행 결과·정적 분석·선택한 함수의 디컴파일 근거 전송을 허용하는 추천 설정을 적용합니다. 전체 원본 소스 파일·바이너리·DB·전체 로그를 일괄 전송하는 설정은 아닙니다. 새 추천 연결은 문맥 예산 32768, 출력 요청 4096, 업무당 최대 요청 5회, 대기 시간 300초를 사용합니다. 기존 연결의 직접 수정한 예산은 보존합니다.

기능 확인은 대상 프로그램 자료를 보내지 않는 작은 요청 최대 4회입니다. 현재 연결과 동일하게 결합된 보호된 검사 결과가 있으면 재사용합니다. ChatGPT 이용 한도가 적용되며, 앱의 호출 수·시간·수신량 제한은 계정의 금액 한도가 아닙니다. ChatGPT plan의 출력 토큰 값은 서버가 강제하는 상한이 아닌 요청값입니다.

## 다른 AI를 쓰려면

**다른 AI 사용 · 세부 설정**을 펼쳐 연결을 추가하거나 선택합니다. 연결 이름, 제공자, 연결 방법, 모델을 지정하고 필요한 키를 앱의 보안 입력 칸에 저장하세요. 전송 범위를 확인해 **연결 설정 저장 → 추론 기능 검사 → 분석 AI로 사용**을 누릅니다. 연결 상태 확인과 실제 답변 생성은 구분됩니다.

| 선택 | 필요한 준비 |
| --- | --- |
| Ollama · 내 PC | 설치한 Ollama 서버와 로컬 모델 |
| OpenAI / ChatGPT | 추천 ChatGPT 로그인 또는 별도의 OpenAI API 키 |
| Claude API | Claude Console API 키. Claude.ai 구독 계정 로그인은 지원하지 않습니다. |
| Gemini API | API 키, 또는 본인이 등록한 Google Desktop OAuth 앱과 프로젝트·권한 |
| OpenAI 호환 서버 | 서버 주소·모델·서버가 요구하는 인증 정보 |

실제 계정으로 확인한 경로는 기존 ChatGPT와 이번 Gemini 3.5 Flash-Lite API 키 연결입니다. Gemini의 등록한 Desktop OAuth와 다른 제공자의 모의 프로토콜 검사는 실제 계정 사용 성공과 다릅니다. 자세한 범위는 [인증 상태](AI_AUTH_STATUS.md)를 참고하세요.

## 준비가 멈췄을 때

- 로그인 시간이 지났으면 다시 연결하고 새 브라우저 창에서 승인을 끝내세요.
- 응답 한도 안내가 나오면 해당 계정의 사용량을 확인한 뒤 다시 시도하세요.
- 도구 준비가 필요하면 시작 화면 안내를 따르세요. 설치된 Ghidra·Java·Docker는 자동으로 찾고 연결합니다. 설치되어 있지 않은 프로그램은 화면의 공식 설치 안내를 사용하세요.
- 상세 설정을 바꿨으면 먼저 저장하세요. 설정 중인 다른 작업이 있으면 완료하거나 중단한 뒤 연결합니다.

키와 토큰은 Recheck 자체 Windows 사용자 보안 저장소에서 보호합니다. 연결 해제는 상세 설정의 로그아웃 또는 키 삭제를 사용하세요. 개인 인증 정보는 배포 폴더나 ZIP에 들어 있지 않습니다.
