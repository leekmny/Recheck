# Gemini 무료 API로 처음 연결하기

Recheck 0.1.1의 신규 기본 모델은 **Gemini 3.5 Flash-Lite**입니다. 본인의 무료 프로젝트와 키를 준비하고 실제 응답 확인을 마쳐야 사용합니다. 기존 사용자의 AI 선택은 유지하며 **GPT는 추천 AI**로 제공합니다.

## 1. Google에서 키 만들기

1. [Google AI Studio의 API Keys](https://aistudio.google.com/apikey)를 열고 본인 Google 계정으로 로그인합니다.
2. 처음이라면 이용 조건을 확인합니다. **Create API key**를 눌러 새 프로젝트를 만들거나 본인이 관리하는 기존 프로젝트를 고릅니다. 기존 프로젝트가 목록에 없으면 프로젝트 가져오기가 필요할 수 있습니다.
3. 해당 프로젝트의 사용 등급이 **Free tier**인지 직접 확인합니다. 무료로 사용하려는 경우 유료 업그레이드나 결제 계정 연결을 진행하지 않습니다. 조직 프로젝트의 권한·무료 이용 검증 요구는 Google 안내에 따릅니다.
4. 생성한 키를 복사합니다. 키 값을 채팅·GitHub 이슈·소스 파일·스크린샷에 넣지 마세요.

키는 Google 프로젝트에 연결되며 일부 프로젝트는 무료 이용 전 추가 확인이 필요합니다. 화면 구성과 정책은 바뀔 수 있으므로 [공식 키 안내](https://aistudio.google.com/docs/api-key), [사용 등급](https://aistudio.google.com/docs/rate-limits#usage-tiers)을 함께 확인하세요.

## 2. Recheck에 안전하게 저장하기

1. **시작하기 → Gemini 무료로 시작하기**를 누릅니다.
2. 안내에서 본인의 프로젝트가 무료 등급인지 확인하고 Gemini에 선택한 분석 근거를 보낼 범위를 확인합니다.
3. 가려진 **Gemini 개인 API 키 보안 입력**에 키를 붙여넣습니다. 무료 프로젝트 확인과 근거 전송 동의 두 확인란을 선택합니다.
4. **Gemini 키 보안 저장하고 응답 확인**을 누릅니다. 입력값은 화면에서 지우고 키를 보호하여 저장합니다. 사용 가능한 무료 모델과 실제 기본 응답·JSON 형식·검사 결과 저장을 확인한 뒤 분석 AI로 사용합니다.

키는 Windows 현재 사용자의 DPAPI 보안 저장소에 보관합니다. 배포 ZIP에는 개발자 공용 키나 다른 사용자의 키가 들어 있지 않습니다. 각 PC에서 자신의 연결을 만들며 인증 파일을 복사해 이전하지 않습니다.

## 3. 결과를 확인하기

모델 목록 확인만으로 연결을 마치지 않습니다. 실제 기본 응답과 JSON 형식이 확인되고 보호된 검사 결과가 저장돼야 준비 완료입니다. 실패·취소·연결 설정 변경이 있으면 이전 AI 선택을 유지합니다. 실패 시 표시된 한도·권한·네트워크 안내를 확인한 뒤 명시적으로 다시 실행하세요.

Recheck는 검토한 무료 제공 모델 목록 안에서만 무료 시작 모델을 고릅니다. 기본은 실제 연결을 확인한 `gemini-3.5-flash-lite`이며 명시적으로 선택한 유효한 무료 모델·예산은 보존합니다. 무료 모델이 없다고 유료 모델을 자동 선택하지 않습니다. Gemini 4 Hydrogen은 별도 선택 후보지만 초기 작은 기능검사에서 출력 한도 초과가 있었으므로 기본값으로 사용하지 않습니다.

무료 등급에는 프로젝트별 요청·토큰 한도가 있습니다. **응답 성공은 무료 프로젝트나 무제한 사용의 증명이 아닙니다.** 실제 등급과 한도는 AI Studio에서 확인하세요. 무료 입력·응답은 Google의 제품 개선에 사용될 수 있습니다. 비공개 자료를 보내기 전 [가격표와 데이터 조건](https://aistudio.google.com/docs/pricing), [약관](https://aistudio.google.com/docs/terms), [한도 안내](https://aistudio.google.com/docs/rate-limits)를 확인하세요.

## 추천 GPT로 바꾸기

GPT를 쓰려면 **ChatGPT로 연결하고 자동 설정**을 눌러 자신의 계정으로 로그인합니다. 기존 Gemini 연결을 지우지 않고 선택할 수 있습니다. 계정별 이용 한도가 적용되며 Gemini 무료 API 할당량과 별개입니다. 다른 연결은 [AI 연결 안내](AI_CONNECTIONS.md), 실제 확인 범위는 [인증 상태](AI_AUTH_STATUS.md)를 따릅니다.
