# 캡스톤 디자인 공개 범위

Recheck의 공개 목적은 프로그램 비교 도구의 구현·테스트·검증 범위를
검토할 수 있게 하는 것입니다. 열람과 프로그램의 완성도, 오픈소스 재사용
권한, 외부 구성요소의 재배포 조건을 각각 구분합니다.

## 공개하는 자료

- Recheck 원본 소스, 고정 의존성 목록, 빌드 정의와 Dockerfile
- 자동 테스트, 직접 만든 무해한 소규모 소스·정답 샘플
- 사용법, 아키텍처, 실제 검증과 미검증 범위의 요약
- 공개 시작점 이후의 검토된 커밋·PR·CI 기록
- 새 버전의 검증된 Windows EXE ZIP과 동봉 라이선스·대응 소스·교체 안내

기존 개인 작성자 정보가 공개되지 않도록, 검토한 현재 소스만 새 Git 이력으로
구성합니다. 과거 커밋·PR·Actions·태그는 별도의 비공개 보관 저장소에 남깁니다.
공개 시작점 이후의 커밋 작성자 정보와 Actions 로그도 공개되므로 noreply 주소와
민감 정보 제외를 계속 확인합니다. 비공개로 되돌려도 이미 복제된 자료까지
회수할 수 있다고 가정하지 않습니다. [공개 이력 구성](PUBLIC_HISTORY.md)과
원본 코드의 재사용 범위인 [LICENSE](../LICENSE)를 확인하세요.

## 로컬 또는 비공개 보관본에 보존하는 자료

- API 키·OAuth 토큰·계정 설정·암호화 인증 파일·앱 데이터베이스
- 개인 분석 프로그램과 실행 결과, 원시 QA·대용량 검증 자료
- Windows ISO·VM 디스크·모델 가중치·개인 설치 환경
- 기존 개발 커밋·PR·Actions·태그와 Windows 실행 ZIP·동봉 이미지:
  별도의 비공개 보관 저장소에 보존

기존 태그와 ZIP 자체를 새 내용으로 덮어쓰지 않습니다. 비공개 보관은 기존
기능 검증 결과나 파일 해시를 바꾸는 것이 아닙니다. 공개 저장소에는 이전
태그·릴리즈를 복사하지 않으며 새 버전은 별도 릴리즈 ZIP으로 제공합니다. 비공개 기록의
README·PR이 설명하는 게시 상태는 당시 기록입니다.

## 새 실행 파일 배포

Python·PySide6/Shiboken6·Qt 및 동봉 Docker 이미지 안의 구성요소를 정확한
버전과 해시로 목록화해야 합니다. 원문 라이선스·저작권 고지, 해당 구성요소의
소스 및 교체·재링크 권리 등 적용 조건을 검토하고 배포물에 필요한 자료를
포함합니다. 링크나 요약 표만으로 모든 재배포 조건을 충족했다고 표시하지
않습니다. 공개 범위 점검과 실제 EXE·원시 정답·전체 ZIP 검증을 모두 마친
새 버전을 별도 태그와 릴리즈로 게시합니다. 기존 ZIP을 조용히 교체하지 않습니다.

0.1.2 Windows ZIP에는 Recheck.exe와 실행용 Python·Qt, 실제 라이선스 고지·대응 소스 자료를 포함합니다.
분석용 Docker TAR는 포함하지 않으며 앱의 명시적 준비 작업에서 각 PC에 도구를 구성합니다.
호스트 Git·Python은 앱 실행 조건이 아닙니다. 설치와 사용 조건은
[처음 실행](FIRST_RUN.md), [바이너리 배포 자료](BINARY_DISTRIBUTION.md)를 따릅니다.

Gemini 무료 시작 안내에는 각 사용자가 자신의 키를 발급·저장하는 절차만 제공합니다.
개발자의 API 키·공용 인증·검증에 사용한 사용자 키를 포함하지 않으며 무료 등급을
유료로 자동 변경하지 않습니다. 키와 보호된 검사 결과는 Windows 현재 사용자 보안
저장소에 둡니다. [Gemini 무료 연결](GEMINI_FREE_SETUP.md)의 무료 제공·데이터 이용 조건을 확인하세요.

ZIP 기반 패키지의 구성 비교는 [정해진 제한](PACKAGE_COMPARISON.md) 안에서 경로·종류·
크기·내용 해시만 검사합니다. APK·MSIX 등의 앱 유효성·서명 검증이나 코드/실행 비교를
완료했다고 표시하지 않습니다. 실제 분석 대상·결과를 외부로 자동 게시하지 않습니다.

현재 공개 소스는 새 관리·문서 수정을 포함할 수 있으며, 과거 EXE의 원본
소스는 비공개 보관 저장소의 해당 태그와 embedded source identity가 기준입니다. 현재 상태와
타사 구성요소는 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)를 확인하세요.

기여·추가 이용 허가는 관리자와 별도로 합의하세요. 민감한 보안 제보에는
[SECURITY.md](../SECURITY.md)를 따르며 인증 정보나 개인 분석 원본을 공개
Issue에 첨부하지 않습니다.
